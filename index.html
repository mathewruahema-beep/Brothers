Runbooks

The jobs that will actually come up while you're travelling, with the traps marked.

Close a Salesforce Case — the two-field trap

A validation rule blocks closing without a reason. Set both fields together or the write fails:

Status = "Closed"
Case_Closed_Reason__c = "Closed - Resolved"   (or another valid reason)

Valid close reasons: Closed - Resolved · Closed - Resolved First Call · Closed - Email Sent · Closed - Email Edited & Sent · Closed - Phone Call · Closed - No Action Required · Closed - Internal Follow up · Closed - Duplicate · Closed - Spam · Closed - Abandoned · Closed - Autoreply · Closed - Returned Letter

While you're in there: ~48% of cases have a blank sub-type (SC_Additional_Enquiry_Type__c). Filling it on close quietly improves every future report.

Triage the zeus queue
  1. Scope: cases with record type Zeus and IsClosed = false.
  2. Read the case and its comments/emails before acting — a "quick close" often has a reply waiting.
  3. Classify: resolved → close (see runbook above) · waiting on requester → Waiting Response-External (system flips it to Response Received when they reply) · in-flight → In Progress · someone else's → reassign.
  4. Real dev work? Create/link an Asana task in IT Operations and close the case pointing to it — track work where it happens.

Statuses: New · In Progress · Pending · On Hold-Internal · Waiting Response-External · Response Received · Closed

Reassigning? Query the User by name and confirm the right record — don't trust a remembered ID.
Onboard a new starter
  1. Create the Entra user (check the Employment Hero starter record if the feed exists).
  2. Assign licence — new starters get M365 Business Premium.
  3. Add to the right groups and distribution lists; set manager.
  4. Confirm MFA registration on day one.
  5. Note any SaaS outside SSO (Asana, Canva, Salesforce) that needs a separate invite.
  6. Update the originating case: status + internal note.

These are Entra admin actions — no admin connector is live, so run them yourself in the console or hand the checklist to Andrew/Keith.

Offboard a leaver — security-critical, do it on the last day
  1. Block sign-in / disable the Entra account.
  2. Revoke all sessions (Entra → user → revoke sessions).
  3. Convert mailbox to shared; grant manager access if requested and approved.
  4. Reclaim the licence.
  5. Remove from groups and DLs.
  6. Sweep SaaS outside SSO: Salesforce, Asana, Canva, WP admin, Stripe, NetSuite, Zapier.
  7. Update the case and log what was done.
MFA or password reset request
  1. Verify identity first — call back on a known number or confirm via manager. A reset request is the classic account-takeover move.
  2. Check Entra sign-in logs for risky sign-ins on the account before resetting.
  3. Reset MFA methods and require re-registration in Entra → user → authentication methods.
  4. Graph session if scripting: Connect-MgGraph -Scopes "User.ReadWrite.All","UserAuthenticationMethod.ReadWrite.All"
  5. Log it on the case.
Phishing report triage
  1. Get the original as an attachment (headers matter), not a forward of the body.
  2. Check Defender (security.microsoft.com) → Explorer for other recipients of the same message.
  3. If anyone clicked/entered credentials: treat as the MFA-reset runbook for that user, plus revoke sessions.
  4. Quarantine/delete campaign messages from Explorer.
  5. Reply to the reporter (thank them — it keeps reports coming), close the case Closed - Resolved.
Website incident (birdlife.org.au)
  1. Confirm scope: site down vs slow vs checkout broken. Check from your phone off-VPN.
  2. WP Engine portal → environment birdlifeaus → check PHP error logs, restore points.
  3. Cloudflare dashboard → check for a traffic spike (cart-flood pattern has happened before); "Under Attack" mode is the big red lever.
  4. Checkout/payment issues: check a recent WooCommerce order carries its payment and Salesforce sync references — any missing on an order more than a few minutes old = broken sync.
  5. Never promote staging naively — staging config differs from production in ways that break payments.
